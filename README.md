# Construction Company Website | موقع شركة مقاولات

A professional, responsive website for a construction company built with HTML5, CSS3, and Bootstrap 5.

موقع تعريفي احترافي ومتجاوب لشركة مقاولات، تم بناؤه باستخدام تقنيات الويب الحديثة.

## 🚀 Features | المميزات
- **Modern UI/UX**: Clean and professional design. | تصميم عصري واحترافي.
- **Fully Responsive**: Works on all screens and mobile devices. | متوافق تماماً مع جميع الشاشات.
- **Interactive Carousel**: Engaging hero section for showcasing projects. | سلايدر تفاعلي لعرض المشاريع الكبرى.
- **Client Testimonials & Icons**: Professional icons from Font Awesome. | عرض الخدمات وآراء العملاء بأيقونات احترافية.
- **Optimized Performance**: Fast loading and smooth transitions. | أداء سريع وتجربة مستخدم سلسة.

## 🛠 Tech Stack | التقنيات المستخدمة
- **HTML5**
- **CSS3** (Custom Styles)
- **Bootstrap 5** (Responsive Grid & Components)
- **JavaScript** (Animations & Interactivity)
- **Font Awesome** (Icons)
- **Google Fonts** (Roboto Condensed)
